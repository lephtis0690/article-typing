# チャレンジモード（試作・ローカル版）

期間ごとに決めた１つの課題文章を、全員同じ条件で打って純字数の自己ベストを競うモードです。
現在はサーバーを使わず、記録は各利用者のブラウザ（localStorage）に保存されます。

## 遊び方

1. 画面上部の「チャレンジ」ボタンを押す
2. 「挑戦する」または Esc キーで開始（3秒のカウントダウン後に計測開始）
3. 制限時間まで打つと記録になる（途中で中断した場合は記録の対象外）
4. 「チャレンジを終える」で通常の練習に戻る（表示モード・表示補助・終了条件・失格ライン・課題選択は元の設定に戻る）

## ルール（固定）

- 表示モード：本番モードを強制（入力中の時間・正解数などの数値、正誤の色分けは非表示。誤りは結果画面で確認）
- 制限時間：1分（`rules.timeLimitSeconds`）
- 開始方法：3秒後に開始
- 失格ライン：10エラー（`rules.disqualifyLimit`）
- 順位：純字数が多い → エラーが少ない → 先に記録した、の順
- チャレンジ中は課題管理・初心者モード・ランダム再挑戦を使えない

## 課題の切り替え方

`data/challenge/schedule.json` の `challenges` に行を追加します。

```json
{ "id": "2026-w44", "textId": "課題ID", "start": "2026-10-26T00:00:00+09:00", "end": "2026-11-02T00:00:00+09:00" }
```

- `id` は期間ごとに一意にする（記録はこの id ごとに保存される）
- `textId` は `data/texts/*.json` の `id`
- `end` の時刻になった瞬間に終了する（上の例は 11月1日（日）いっぱいまで）
- 期間は重ねない

変更したら、`js/modules/80-challenge.js` の `CHALLENGE_SCHEDULE_FALLBACK` も同じ内容にしてから `npm test` を実行します
（JSONを読めない環境向けの予備データです。内容が違うとテストが失敗します）。

## 保存先

- localStorage キー：`long-type:challenge-records:v1`
- 期間ごとに、自己ベスト・挑戦回数・直近50回の履歴を保存
- 通常の「記録を見る」の履歴にも、チャレンジの結果は1分の練習として残る

## オンラインランキング

- サーバー側：`ranking-worker/`（Cloudflare Workers + D1）。準備と運用の手順は `ranking-worker/README.md`。
- 画面側：`js/modules/85-ranking.js`。接続先は `js/ranking-config.js` の `RANKING_API_BASE`（空のままならランキングは表示されない）。
- 結果画面の「ランキングに登録」を押した記録だけを登録する。対象は制限時間まで打ち切った失格でない記録。
- 同じブラウザ（自動で作る識別番号 `long-type:ranking-client-id`）からの登録は1期間1件。より良い記録のときだけ上書き。登録回数の制限はなし。
- 表示は上位50位。自分の順位は圏外でも表示する。
- 純字数はサーバーで入力文字列から採点し直し、人間離れした速度の記録は受け付けない。
