GitHub Pagesでは、このフォルダ内の5ファイルを同じ階層にアップロードしてください。課題文を増やす場合は texts.json に {"id","title","text"} を追加します。段落間の空白行は入れず、段落冒頭は全角スペースで一字下げしてください。
今回の版では、課題文の選択欄に「ランダム（毎回）」を追加し、デフォルトで開始時ごとに課題文がランダム選択されます。手動で特定の課題文を選んだ場合は、その課題文で練習できます。


補足: ローカルでHTMLファイルを直接開いた場合、ブラウザの制限で texts.json の fetch が失敗することがあります。この版では内蔵データも4題に更新しているため、その場合でも4題が選択欄に表示されます。GitHub Pagesでは必ず index.html / script.js / style.css / texts.json / README.txt を同じ階層に置いてください。


重要: GitHubにアップロードするファイル名は必ず index.html / script.js / style.css / texts.json / README.txt にしてください。index(33).html や script(8).js のような名前のままだと、GitHub Pagesでは古いファイルや別ファイルを参照してしまうことがあります。
